One image that sums up the world news of Tuesday 24 November 2026: 26 stories in a single 1024x1024 poster. The lead story is the Strait of Hormuz crisis — Iran says four tankers hit naval mines and its navy attacked a container ship — with the Huawei verdict in New York, Ukraine's strikes on Russian ships, the ICJ ruling that Myanmar committed genocide, and 22 more stories across every region, each pinned on a world map. All stories were researched from that day's reporting; SOURCES.md lists them, stories.json holds the copy, and render.py (Python/PIL) draws entry.png. main.ts copies entry.png to the output directory, as the grader expects.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
